# entities-scene-japanese-classroom

A Godot 4 classroom scene with baked lighting, set up as a V-Sekai world project.

## What it is for

It is a world for avatars to stand in: the classroom model with a lightmap bake, and the V-Sekai addons it runs with as submodules.

## Run

```sh
git submodule update --init
```

Then open the project in Godot 4 and open the classroom scene. The project's configured main scene names a path this repository does not hold.
